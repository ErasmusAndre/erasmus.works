My own cloud.

This is Erasmus.works, where I host my own digital infrastructure. My photos, files, documents and home automation run on a small Kubernetes cluster at home. It sits in a 10-inch rack I cut from aluminium extrusion, on mounts I designed and 3D printed myself.

The cluster repo The rack build

Services

What is actually running.

Photos go to Immich instead of Google Photos. Files go to Nextcloud instead of Dropbox. Notes and documents go to Docmost, and my home runs on Home Assistant.

TrueNAS holds the bulk storage behind them. Authentik gives all of them one login, and none of it needs an open port on the router.

Software

Every cluster change is a pull request.

Argo CD is the only thing that touches the cluster. Renovate opens the dependency pull requests, and merging one is the deploy. Rebuilding a node from bare metal takes a single talosctl apply-config. Nothing is applied by hand from a laptop.

What the cluster is made of.

  • Talos Linux Immutable node OS
  • Kubernetes Runs the containers
  • Argo CD Applies what Git says
  • Renovate Opens update PRs
  • Envoy Gateway Ingress and routing
  • MetalLB LoadBalancer IPs
  • ExternalDNS DNS from manifests
  • Cloudflare Tunnel, no open ports
  • Longhorn Persistent volumes
  • CloudNativePG In-cluster Postgres
  • VolSync Scheduled backups
  • Garage S3 for backups
  • Bitwarden Stores the secrets
  • External Secrets Pulls secrets into the cluster
  • Prometheus Metrics and alerts
  • Grafana Dashboards
  • VictoriaLogs Log storage
  • Fluent Bit Log shipping

Hardware

Ten units, cut from four metres.

The rack is 2020 aluminium extrusion, slot 6 throughout: 220 mm wide, 240 mm deep, 445 mm tall. Twelve pieces come out of four one-metre lengths, with 380 mm left over for saw kerf. Machines that do not fit a rack get 3D-printed mounts. The models are published as STEP and 3MF under CERN-OHL-S.
